# **App Name**: VisionAI

## Core Features:

- Marketing Metrics Dashboard: Dashboard to display key marketing metrics such as total earnings, total orders, and total ratings using cards and graphs.
- Campaign Management Interface: A section to manage and display statistics for social media campaigns, including follower counts, ad performance, and traffic analysis with charts and real-time data feeds (e.g., Twitter mentions).
- SEO Dashboard: SEO dashboard displaying campaign budgets, organic search conversions, lead conversion rates, and profit breakdowns via charts and key performance indicators (KPIs).
- AI Blog Generator: AI Blog Generator tool for generating blog content based on user prompts.
- AI Chat Assistant: AI Chat Assistant integrated for live user support, providing real-time troubleshooting assistance and automated responses.

## Style Guidelines:

- Primary color: White or light grey for a clean, modern look.
- Secondary color: Shades of blue for UI elements and backgrounds.
- Accent: deep purple for interactive elements, call-to-action buttons and highlights.
- Card-based layout with rounded corners and subtle shadows to display metrics and information.
- Use a consistent and professional icon set for the sidebar navigation and other UI elements.
- Subtle transitions and animations to enhance user experience and provide visual feedback.
