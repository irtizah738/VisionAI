# AI API Documentation

## Overview

Our AI API provides a suite of powerful AI-powered features for content generation, analysis, and optimization. All endpoints require authentication via the `x-api-key` header.

## Base URL

```
https://your-domain.com/api/ai
```

## Authentication

All requests must include an API key in the header:

```http
x-api-key: your-api-key-here
```

## Rate Limiting

Requests are limited to 100 per minute per API key. Exceeding this limit will result in a 429 response.

## Endpoints

### Chat Assistant

`POST /api/ai/chat`

Generate AI-powered responses for various queries.

#### Request

```json
{
  "message": "How can I improve my website's SEO?",
  "conversationId": "optional-conversation-id",
  "useCache": true
}
```

#### Response

```json
{
  "message": "Here are some ways to improve your website's SEO...",
  "model": "googleai/gemini-2.0-flash",
  "timing": {
    "startTime": 1234567890,
    "endTime": 1234567891,
    "duration": 1000
  }
}
```

## Error Handling

All endpoints follow the same error response format:

```json
{
  "error": "Error message",
  "details": ["Optional array of detailed error messages"]
}
```

Common HTTP status codes:
- 200: Success
- 400: Invalid request data
- 401: Missing or invalid API key
- 429: Rate limit exceeded
- 500: Internal server error

## Best Practices

1. Always include error handling in your implementation
2. Use the cache parameter when appropriate to improve response times
3. Implement exponential backoff for rate limit handling
4. Keep content lengths within the specified limits
5. Monitor the timing information to optimize your usage
